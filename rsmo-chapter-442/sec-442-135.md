# 442.135. Descriptions of subdivided property, contents.
1. If a property is subdivided and a new property description is created, such property description shall include the name, and professional license number, if applicable, of the person that created the property description.
2. No person shall submit for recording a conveyance of any property under subsection 1 of this section unless the property description of such property contains the information required in subsection 1 of this section.
(L. 2019 S.B. 36)
