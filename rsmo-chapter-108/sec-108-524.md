# 108.524. Expiration, resubmission of application.
In the event an approved allocation expires as provided in section 108.512 or 108.518 , the issuer may resubmit an application for an allocation for the same project. Such resubmitted application shall be reviewed in the order of date received with no preference or priority being given as a result of the prior application for the same project or financing.
(L. 1987 S.B. 351 § 108.519)
Effective 1-01-88
