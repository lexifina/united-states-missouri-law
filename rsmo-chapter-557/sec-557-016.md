# 557.016. Classification of offenses.
1. Felonies are classified for the purpose of sentencing into the following five categories:
(1) Class A felonies;
(2) Class B felonies;
(3) Class C felonies;
(4) Class D felonies; and
(5) Class E felonies.
2. Misdemeanors are classified for the purpose of sentencing into the following four categories:
(1) Class A misdemeanors;
(2) Class B misdemeanors;
(3) Class C misdemeanors; and
(4) Class D misdemeanors.
3. Infractions are not further classified.
(L. 1977 S.B. 60, A.L. 2014 S.B. 491)
Effective 1-01-17
